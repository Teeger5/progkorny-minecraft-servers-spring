# Minecraft Servers - Frontend
Minecraft szervereket megjelenítő oldal megvalósítása React használatával. Alap CRUD műveleteket támogat.\
Ez az első projekt, amiben Vite+React-ot használtam, elég kezdetleges, és csak `localhost` környezetben működik.\
Az indíttatás a projekt mögött, hogy könnyebben lehessen tesztelni egy ilyen oldalhoz tervezett szervert, 
ami itt érhető el: https://github.com/Teeger5/progkorny-minecraft-servers-spring
